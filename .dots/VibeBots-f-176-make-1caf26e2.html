F-176 Make save-slot switches transactional and fail closed

Stage and validate the target save slot before changing live activeSlot state or persisting under the target key. If either world or gear authority fails, return false, keep the popup open with visible Retry and Start fresh recovery, preserve the coherent source slot, and never navigate or write the source trip into the target slot. Cover world-read failure, gear-read failure, target local-trip absence, reload while offline, no cross-slot localStorage writes, and successful atomic commit.
