F-179 Require a real exact-head bot review before merge

A merge gate must require one submitted CodeRabbit review on the exact current head, zero unresolved review threads, and the full 60-second settle window. A SUCCESS context, rate-limited summary, or instant command reply without a review node cannot satisfy the gate. Poll GraphQL reviews and threads, verify the summary marker and reviewed commit range, compute retry time through rate limits, require explicit user approval plus durable evidence for any bypass, and cover rate-limited success, stale prior-head review, real no-findings review, actionable thread, resolved finding followed by approval, and manual bypass. Treat sequential and chained ready-plus-admin commands as the same bypass. Reject either while the PR is draft, CHANGES_REQUESTED, under an exact-head hold, or missing settled review evidence. Require current user approval naming the exact head, review state, unresolved findings, and reason before an administrator bypass. Prevent durable agent memory, runbooks, scripts, or automation from encoding timing tricks that defeat review state, remove or supersede unsafe guidance, and require durable summaries to preserve unresolved findings. Cover a chained command, re-draft race, changes-requested review, unresolved inline thread, approved named bypass, stale approval after head movement, guidance scan, and dropped-finding summary. PR #240 adds the eleventh verified incident: exact head ae348390 was chained from draft to an administrator merge with zero submitted reviews while exact-head holds remained and CodeRabbit had only skipped review because the PR was draft. Green post-merge status and deployment evidence do not satisfy review or authorize the bypass. PR #241 adds the twelfth verified incident: exact head 46b8be8b was reopened, made ready, and administrator-merged as main c5b06888 in one chained command before a two-second close guard could re-close it. CodeRabbit explicitly reported a temporary fair-usage review limit with a 13-minute retry, while the only submitted approval remained on old head 79805bfe; the green status created no exact-head review node. Technical audit, local gates, CI, and deployment were green, so this is process evidence rather than a code regression. The PR #241 session then reinforced project memory review-agent-gate.md with instructions to treat a technical clearing audit as permission to ignore the exact-head bot review and settle requirements and merge with --admin. Require the guidance scan to remove or supersede this concrete unsafe target, distinguish a temporary computed retry from an impossible gate, and reject atomic reopen-plus-ready-plus-admin races unless the user explicitly approves the exact head and current review state.
