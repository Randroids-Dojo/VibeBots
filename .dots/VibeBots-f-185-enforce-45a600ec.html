F-185 Enforce append-only records across PR commit history

Reject a PR when a committed progress article, followup history pair, open-question record, or GDD build-log item is later edited, deleted, or reordered. Compare merge-base-to-head commit history, allow only documented state and reference updates plus appended correction records in their required positions, retain exact failure evidence, and cover new records, later rewrites, deletion, reorder, correction, approved history replacement, and base movement.
