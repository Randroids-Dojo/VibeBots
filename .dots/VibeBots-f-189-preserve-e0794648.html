F-189 Preserve failure status in local verification output

Provide one dependency-free canonical local verifier that runs the required dash check, git diff check, full lint, typecheck, relevant tests, and any configured broader gates while preserving every subprocess exit status. Concise output must be captured only after the command status is saved, never through a terminal pipeline whose final formatter can mask an upstream failure. Add regression fixtures where a failing upstream command followed by successful output filtering still makes the verifier exit nonzero, cover multiple failures and signals, identify the failed gate with bounded diagnostics, and document the canonical command in the implementation plan or working agreement. Do not change CI workflow configuration in this slice.
