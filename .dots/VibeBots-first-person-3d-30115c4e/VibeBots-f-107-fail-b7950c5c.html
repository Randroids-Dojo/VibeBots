F-107 Fail fast on unsupported raid state

F-107: Reject incompatible active raid versions with a clear explanation and confirmed Start fresh recovery. Do not maintain old resolvers indefinitely.
LiveRaidActiveView currently omits raid version and the client ignores authored duration. Require matching row and snapshot versions plus a supported duration before runtime creation, or show the confirmed Start fresh recovery. Never run current constants over incompatible state.
Main c84a4403 still defaults a missing snapshot version to current, can normalize an unknown row toward interim state, and sends no persisted raid version to the live client. Reject missing, malformed, old, or future state with one stable explanation and a confirmed Start fresh action that abandons it without reward. Do not add a migration chain.
The draft filters to current raid version but returns success when an unsupported unresolved row remains. Return the fail-fast incompatible-state response and confirmed Start fresh recovery. Never silently skip bad state and unlock normal play.
Treat the server-authored durationSeconds as required compatibility data. Before runtime creation, require a finite positive integer exactly equal to the build's shared BUNKER_RAID_DURATION_SECONDS value, then initialize runtime timing from that received server value. Missing, malformed, non-finite, fractional, non-positive, or mismatched values enter the same confirmed Start fresh incompatibility path. Never substitute the client constant, clamp the value, or continue with a default. Accelerated test fixtures do not weaken the production gate.
Main d722ae8e silently ignores the newest unresolved row when its raid version is unsupported or its live snapshot is malformed. The row remains stored, can control cooldown, and can coexist with a later live row. The live-only route also accepts the stale flat client's tier-only body. Require an explicit protocol discriminator, structured incompatibility body, confirmed Start fresh recovery, and reload proof. Never hide, infer, migrate, or reinterpret unsupported active state.
