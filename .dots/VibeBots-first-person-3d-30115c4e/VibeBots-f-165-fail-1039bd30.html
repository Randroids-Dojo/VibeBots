F-165 Fail visibly on incompatible bunker wire state

Add an explicit bunker wire and stored-state compatibility boundary. A stale loaded client must receive a stable refresh-required response instead of dereferencing a missing field into a blank scene. Cover old-client and new-server skew plus unsafe rollback to an old server after null-core writes. Incompatible alpha state must explain the problem and offer confirmed Start fresh recovery. Bound any temporary bridge, then remove the cold-start DROP NOT NULL migration path. Do not carry permanent silent migration chains.
