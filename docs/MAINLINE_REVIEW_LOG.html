Mainline Review Log

Append-only cursor for the post-merge adversarial review required by the continuous-mainline contract (docs/WORKING_AGREEMENT.html, Mainline Integration). Pre-merge bot review is retired; this log is where review happens instead.

Each entry records the reviewed mainline range. The cursor for the next review is the newest entry's head sha. File actionable findings as docs/FOLLOWUPS.html entries or docs/OPEN_QUESTIONS.html entries, never as merge blocks, and reference their ids here. Newest entries first. Never edit or delete a past entry.

Review posture is adversarial: read every squash commit in the range as if it were a PR you had to approve, looking for correctness, determinism (src/sim purity, SIM_VERSION bumps), frame-loop allocation, ledger hygiene, and copy that contradicts the GDD. Do not soften a finding because the code already shipped; a shipped defect becomes a followup, not a footnote.
