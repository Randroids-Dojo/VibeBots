0.1.29

Package version
0.1.29
Gameplay versions
MINE_VERSION moved from 27 to 28. SIM_VERSION stays at 3.
Highlights
Dynamite is now a four-tier selector. The HUD shows every tier, previews the mine cells the selected tier can destroy, and deploys only after the check button is pressed.
Rules
All tiers use the same dynamite stock. Stronger tiers are permanent one-time Blast Charge unlocks from the Upgrades stall. Tier 1 is the base plus, tier 2 is a longer plus, tier 3 is a 3x3 block, and tier 4 wipes blastable cells inside lamp range.

0.1.24

Package version
0.1.24
Gameplay versions
MINE_VERSION stays at 25. SIM_VERSION moves from 2 to 3.
Highlights
Battle bots now run a deterministic target-scoring brain instead of only steering at the opposing core. Each bot scores enemy parts by category, remaining health, structural importance, exposure, reachability, weapon danger, and its own weapon fit.
Behavior
Weaponed bots aim so their weapon side reaches the selected target. Out-weaponed or damaged bots can take safer flank approaches and target mobility. The brain retargets on a short deterministic cadence with hysteresis so bots can exploit weak points without flickering between equal choices.
Compatibility
Official match requests using older sim versions are rejected as stale because match outcomes changed.
Verification
Ran focused and full verification after rebasing onto the latest origin/main. Full command list is recorded in the progress log for this slice.
