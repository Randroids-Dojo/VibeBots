0.1.20

Package version
0.1.20
Gameplay versions
MINE_VERSION moved from 23 to 24. SIM_VERSION stays at 2.
Highlights
Elevator controls now work from the miner's current column anywhere from the surface through the owned elevator depth. Players no longer need to walk back to the tower column just to ride.
Interface
The down button appears when the miner can descend within owned elevator depth, and the up button appears once the miner is below the surface in that depth. Auto-rides now continue until the owned depth or surface without canceling because the miner is away from the tower.
Rules
Ride-down clears the current lift path as it travels, keeps the miner in that column, and still stops at the owned elevator depth. Ride-up keeps the same column and sells the haul when it reaches the surface.

0.1.18

Package version
0.1.18
Gameplay versions
MINE_VERSION stays at 23. SIM_VERSION stays at 2.
Highlights
Long-running mine trips with stale ladder or plank snapshots no longer fail cash-out just because the submitted support count is above the stored support count. Server replay uses the server-owned support stock and credits only what that replay can actually sell.
Security
Dynamite, rope, and beacon overclaims still hard-fail before replay. The relaxed path applies only to ladder and plank snapshot drift, which cannot inflate payout because replay ignores the submitted support count.
Operations
The fix was traced from Vercel production alert logs showing repeated mine.cash_out.consumables_not_owned events with detail="support consumable overclaim", where submitted ladder stock was one above owned stock for the same long-running mine.

0.1.1

Package version
0.1.1
Gameplay versions
MINE_VERSION moved from 18 to 21. SIM_VERSION stays at 2.
Highlights
Mining movement now settles unsupported miners through empty cells instead of leaving them floating or refusing lateral movement. A base miner survives free falls up to 4 cells, and longer falls collapse the trip like a falling-rock crush unless Fall Harness upgrades raise the safe distance. Planks no longer auto-deploy: the explicit plank button places them left or right, including under a solid block before mining it. Visible collect mode returns placed ladders and planks to inventory, and recovered supports are accounted for during server replay. A full cargo hold no longer blocks digging: overflow ore falls to the nearest surface, stacks with a count label, and can be picked up later. Failed trips record the dropped-cargo location for a proximity-pulsing locator chip. Cash-out messages auto-hide after a short delay.
Maintenance
@randroids-dojo/vibekit is pinned to v0.3.0, with additive upstream helper changes and no required VibeBots code migration. Elevator rail construction now refunds ladders it replaces, and ladder/plank placement is blocked while riding the rail.
Backlog
Closed the mine backlog items for unsupported side digging, ladder and plank recovery, temporary cash-out messages, dropped-cargo location feedback, floating after collapse, explicit plank deployment, cargo-overflow drops, and fatal free falls with an upgrade path.
