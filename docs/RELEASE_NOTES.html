0.1.1

Package version
0.1.1
Gameplay versions
MINE_VERSION moved from 18 to 21. SIM_VERSION stays at 2.
Highlights
Mining movement now settles unsupported miners through empty cells instead of leaving them floating or refusing lateral movement. A base miner survives free falls up to 4 cells, and longer falls collapse the trip like a falling-rock crush unless Fall Harness upgrades raise the safe distance. Planks no longer auto-deploy: the explicit plank button places them left or right, including under a solid block before mining it. Visible collect mode returns placed ladders and planks to inventory, and recovered supports are accounted for during server replay. A full cargo hold no longer blocks digging: overflow ore falls to the nearest surface, stacks with a count label, and can be picked up later. Failed trips record the dropped-cargo location for a proximity-pulsing locator chip. Cash-out messages auto-hide after a short delay.
Maintenance
@randroids-dojo/vibekit is pinned to v0.3.0, with additive upstream helper changes and no required VibeBots code migration. Elevator rail construction now refunds ladders it replaces, and ladder/plank placement is blocked while riding the rail.
Backlog
Closed the mine backlog items for unsupported side digging, ladder and plank recovery, temporary cash-out messages, dropped-cargo location feedback, floating after collapse, explicit plank deployment, cargo-overflow drops, and fatal free falls with an upgrade path.
