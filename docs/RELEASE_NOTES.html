Highlights
Battle bots now run a deterministic target-scoring brain instead of only steering at the opposing core. Each bot scores enemy parts by category, remaining health, structural importance, exposure, reachability, weapon danger, and its own weapon fit.
Behavior
Weaponed bots aim so their weapon side reaches the selected target. Out-weaponed or damaged bots can take safer flank approaches and target mobility. The brain retargets on a short deterministic cadence with hysteresis so bots can exploit weak points without flickering between equal choices.
Compatibility
Official match requests using older sim versions are rejected as stale because match outcomes changed.
Verification
