Test Arena

Status: partial

Spec

Players can test a valid bot against a CPU robot before online combat (REQ-009). The test fight runs the same deterministic match the server will later use for official results: same assembly, same controller, same damage model. The workshop is the entry point: build, validate, test, adjust, repeat.

Debrief

A test fight ends with a debrief: a headline (won, lost, or drew; by knockout or decision; when) and at most two lessons drawn from the match teardown in a fixed order (a weapon that never connected or no weapon at all; the part that went first and what took it; the part that soaked half or more of the damage; a decision lost on the score; for a win, the surviving part that came home weakest). Each lesson has a fix-it action that returns the player to the bench with the relevant part in hand, the weak part selected, or the Tune tab open, so build, test, learn, tweak is one loop. The lessons are deterministic rules over the same teardown the inspection sheet shows.

What this does NOT cover yet

  • Choice of CPU opponent (only the stock Brawler).
  • Match seeds or variations (every test replays the same deterministic fight for a given design).
  • Carrying results anywhere (rewards and persistence are later slices).
