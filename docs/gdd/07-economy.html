Economy

Status: partial

Spec

Players convert mining output into robot components (REQ-008). Trust comes from determinism, not from the client: a mining session is a pure function of (seed, move log), so cashing out submits the log and the server replays it to credit exactly what an honest client banked.

The conversion flow

  • Each mine session has a random seed and records every attempted move. Cashing out submits (seed, moves); the server replays, credits emeralds and found parts, and consumes the seed (one credit per player per seed; resubmission is rejected).
  • After a cash-out the session restarts with a fresh seed: new mine, new finds.
  • The shop sells catalog parts for emeralds at fixed prices; purchases are atomic conditional spends (no negative balances under concurrency). Inventory is per player.
  • Cores are starter gear and are not sold.

What this does NOT cover yet

  • The workshop does not yet consume inventory (any part is buildable); gating is followup F-010.
  • Player-to-player trading, combat reward payout into the same wallet, pricing balance.

Build log
