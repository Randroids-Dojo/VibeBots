Notifications

Status: done

Spec

Players may opt into native browser notifications for release updates. The first notification type is a one-line version summary sent after a new VibeBots release is deployed.

  • Notification permission is requested only after a direct player tap. Browsers must never see an automatic prompt on page load.
  • Subscriptions use standards based Web Push with VAPID keys and a service worker. Each release notice id is sent once per enabled subscription.
  • Android Chrome can subscribe from the browser when Web Push is available.
  • iPhone and iPad Safari can subscribe only after the player installs VibeBots as a Home Screen web app and opens that installed app. The Settings menu must guide this state instead of showing a broken prompt.
  • Mobile Safari outside Home Screen mode should also get a dismissible Home Screen reminder before notifications are available. Ok is a current page-session dismissal; Never show again is a durable local opt-out.
  • Release notification copy is sourced from the same release metadata that powers the in-game release notes, so app popups and native alerts stay aligned.
  • The mine should also detect when the currently loaded page is older than the deployed app version and offer a player-controlled refresh prompt.
